# PUApplePay

Lets you make payments via Apple Pay

## Overview

This package provides models, services, extensions etc. to allow customers to make payments via Apple Pay. It uses ``PaymentRequest`` as a main data holder for payments details. For more details please visit: [developers.payu.com](https://developers.payu.com/europe/docs/payment-solutions/cards/digital-wallets/apple-pay/)
